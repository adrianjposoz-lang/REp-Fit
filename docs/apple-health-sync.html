REp-Fit Setup Guide

Apple Health Sync

Auto-import your Apple Watch steps, calories, weight, and workouts into REp-Fit every morning — via a private GitHub Gist. No subscriptions, no data-sharing.

Time: ~10 min, one-time
Cost: $0
Needs: iPhone · GitHub account

How it works

Apple Watch → iPhone Health app → iOS Shortcut → private GitHub Gist → REp-Fit (data) (stores data) (runs daily) (JSON file) (fetches + merges)

An iOS Shortcut writes yesterday's Watch data to a private gist each morning. The REp-Fit app fetches that gist on open and merges it in. One-way only — nothing leaves REp-Fit back to Apple Health.

1Create a private gist · 2 min

  1. Go to gist.github.com
  2. Filename: repfit.json
  3. Content: {"days":{}}
  4. Click the arrow beside the green button → Create secret gist
  5. Copy the gist ID from the URL — the long hash after your username.
    gist.github.com/you/8f4c2ab9e21b4f9a23b7e8d5c6a1b9e0

2Create a GitHub token · 2 min

  1. Go to github.com/settings/tokens?type=beta
  2. Generate new token → name it REp-Fit Health Sync
  3. Expiration: No expiration (or 1 year)
  4. Repository access: Public Repositories (read-only) — doesn't matter for gists
  5. Permissions → Account → Gists: Read and write
  6. Click Generate token and copy it now. Starts with github_pat_…. You'll only see it once.

3Paste into REp-Fit · 30 sec

  1. Open REp-Fit → tap ⚙️ → Apple Health sync
  2. Paste the Gist ID and the token
  3. Leave Auto-sync on open checked → Save
  4. Tap Sync now — you should see "Already up to date" (empty gist is expected)
Privacy: the token is stored on your device only. It's never included in exports or backups.

4Build the iOS Shortcut · 5 min

Open the Shortcuts app on iPhone → tap + to create a new shortcut, then add these actions in order:

A. Get today's date

  • Date → Current Date
  • Format Date → ISO 8601, Date only (gives 2026-04-19)
  • Rename the result to Today

B–D. Pull Health samples

Repeat Find Health Samples Where three times, one per data type. Each: sort by Start Date · order Latest First · limit 1 · start date Yesterday.

  • Type: Steps → Get Details of Health Samples → Value → rename Steps
  • Type: Active Energy → Get Details → Value → rename ActiveKcal
  • Type: Weight → Get Details → Value → rename Weight

E. Build the JSON payload

Add a Text action. Type the template below, then replace each […] by tapping in the field and selecting the matching magic variable:

{"days":{"[Today]":{"steps":[Steps],"activeKcal":[ActiveKcal],"weight":[Weight]}}}

Rename the result to NewDay.

F. PATCH the gist

Add another Text action with the outer wrapper:

{"files":{"repfit.json":{"content":"[NewDay as text]"}}}

Then add Get Contents of URL:

  • URL: https://api.github.com/gists/YOUR_GIST_ID
  • Method: PATCH
  • Headers:
    • Authorization: Bearer YOUR_TOKEN
    • Accept: application/vnd.github+json
  • Request Body: File → the JSON from the previous Text action

G. Test it

  1. Tap ▶︎ Run
  2. In REp-Fit → Settings → Apple Health sync → Sync now
  3. You should see "Synced · 1 day updated"

5Run automatically every morning · 1 min

  1. Shortcuts app → Automation tab (bottom)
  2. + → Time of Day → 6:00 AM → Daily
  3. Run Immediately (so it doesn't prompt)
  4. Next → pick the Shortcut you just built → done

What syncs

DataDirectionMerge rule
StepsWatch → AppOverwrite (Watch wins)
Active caloriesWatch → AppStored alongside day
WeightWatch → AppOnly fills blanks (never overrides manual)
Watch workoutsWatch → AppAppend to cardio, dedupe
Meals / notes / lifts—Stay in REp-Fit only

Troubleshooting

  • "Gist not found" — wrong ID, or token missing Gists permission.
  • "GitHub API 401" — token expired. Regenerate in step 2.
  • "Gist content is not valid JSON" — open the gist on github.com and fix.
  • Shortcut runs but app doesn't update — tap Sync now to see the error; check the raw gist content.
  • Steps write zero — Shortcut's date filter is Today (empty) instead of Yesterday.
Privacy note: a secret gist is not indexed, but anyone with the URL can read it. Treat it like an unlisted YouTube link. GitHub sees your data transit. If that's not OK, skip gist sync and keep logging manually.
